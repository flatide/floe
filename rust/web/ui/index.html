    About floe2 · Web preview
    
      
    
      
    
      
    Native versions above are the launcher's expected compatibility versions, not source hashes of running tools. Revision “unknown” has no Git provenance; a trailing “+” reports a dirty tree observed at build time. These are diagnostics, not signatures.
    
      
    Linux, Firefox/ETX and shared-server acceptance still require field validation. This panel reads build identity and packaged notices only; it does not run selfcheck, open design files or change the view.
    
      
    Distribution notices
    
      
    Portable packages contain the collected original material in NOTICES/ (starting with INVENTORY.txt). Use verify.sh to check the complete package hashes. The reader below displays one bounded source chunk at a time, not executable HTML.
    
      
    The inventory includes build dependencies and may include components not linked at runtime. It is not legal clearance or a grant of Floe distribution rights. Development executables may have no adjacent notice bundle.
