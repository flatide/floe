Canvas: arrow keys pan 50%, Shift + arrows 10%; + / − zoom, Home fits. Left/middle drag pans; wheel zooms about the cursor. Right drag draws a zoom band: rightward zooms in, leftward zooms out; Escape cancels.

During navigation or display-option changes the previous image stays visible until the current frame arrives. A wait cursor marks pending work; the previous image is not the completed new view.

Your view is independent. Shared layout and index files are read-only here: no file browsing, indexing, review writes, query or export. A lost connection clears the display; Reconnect restores the server's current view without replaying navigation.
