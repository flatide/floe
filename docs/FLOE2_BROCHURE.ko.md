# floe2 홍보 문안

팜플렛·소개 자료에 그대로 옮겨 쓸 수 있는 문장 모음이다. 모든 수치와 주장은
[FLOE2_INTRO.ko.md](FLOE2_INTRO.ko.md)의 실측과 범위를 따른다. 2026-09-18 기준.

## 1. 슬로건 (택 1)

- 라이선스를 기다리지 말고, 바로 보세요.
- 9 GB 레이아웃도 8초. 리뷰는 기다림 없이.
- Calibre로 하던 리뷰를, 라이선스 없이 더 빠르게.

## 2. 리드 문단

floe2는 마스크·레이아웃 리뷰를 위한 고속 뷰어입니다. DESIGNrev·MDPView·RVE로
하던 레이아웃 보기, DRC 결과 리뷰, jobdeck 리뷰, 화면 캡처를 라이선스 서버 없이
폐쇄망 서버에서 그대로, 더 빠르게 합니다. 인덱스는 한 번만 만들고, 이후에는
누구나 바로 엽니다.

## 3. 핵심 메시지

**기다리지 않습니다.**
라이선스 서버도, 동시 사용자 수 제한도 없습니다. 서버 자원이 허용하는 만큼
누구나 동시에 엽니다.

**인덱스는 한 번, 열기는 바로.**
한 번 만든 인덱스를 같은 서버의 모든 사용자가 복사 없이 공유합니다. 9.4 GB
레이아웃도 인덱스가 준비된 뒤에는 8초면 열립니다.

**depth·detail 전환이 1초 안에 끝납니다.**
Calibre가 파일을 다시 읽느라 4분을 쓰는 동안 floe2는 플랜만 다시 계산합니다.

**DRC 리뷰가 뷰어 안에 있습니다.**
결과 DB를 한 번 변환하면 바로 열립니다. 에러 번호는 RVE와 같고, waive와 note는
리뷰어별로 저장되며, SVRF 룰의 제약값과 측정값을 나란히 보여 줍니다.

**jobdeck을 그대로 엽니다.**
MDPView의 `.jb`를 직접 열고 level view와 chip view를 바로 전환합니다. 소스가
600개 넘는 덱의 레티클 전체 뷰가 0.2초에 뜹니다.

**캡처는 CLI 한 줄입니다.**
GUI도, 스크립트 언어도, 라이선스 체크아웃도 없이 배치 캡처를 돌립니다. 에러 도형과
측정 룰러는 PNG 안에 주석으로 남습니다.

**손에 익은 조작 그대로.**
마우스와 키 조작이 DESIGNrev와 같고 `.layerprops`를 그대로 읽습니다. 따로
익힐 것이 없습니다.

**설치 없이 배포합니다.**
tar 파일 하나를 풀면 끝입니다. 폐쇄망에서, GPU 없이, Exceed TurboX 같은 원격 X
환경에서 동작합니다.

**검증된 정확도.**
렌더 결과를 KLayout이 그린 화면과 자동으로 대조하고, 워커 수와 무관하게 같은
요청은 같은 PNG를 만듭니다.

## 4. 숫자로 보는 floe2

| 수치 | 설명 |
|---|---|
| 8초 | 9.4 GB 레이아웃 열기 (Calibre 3분 45초)¹ |
| 0.16초 | 전체 depth로 전환 (Calibre 4분 15초)¹ |
| 5~10배 | 같은 파일을 열어 다 그릴 때까지, Calibre 대비² |
| 0.2초 | 소스 600개 덱의 레티클 전체 뷰, depth 무관 |
| 수십 ms | DRC 결과 DB 열기 (매번 2.7초 파싱 대신) |
| 0 | 라이선스 서버, 호스트 설치, 동시 사용자 수 제한 |

¹ 같은 서버에서 9.4 GB 실제 레이아웃을 Calibre DESIGNrev v2023.2와 번갈아 잰
값. floe2는 인덱스를 미리 만든 뒤 다시 열 때의 값이다.
² 현장 사용자 실측(2026-09). 같은 파일·같은 서버, floe2는 인덱스가 준비된 뒤.

## 5. 업무별 한 줄

- **레이아웃 리뷰**: 라이선스 대기 없이 열고, depth와 detail을 1초 안에 바꿉니다.
- **DRC 리뷰**: RVE 번호 그대로 찾고, 화면에서 골라 waive하고, 리뷰어별 기록이 남습니다.
- **jobdeck 리뷰**: `.jb`를 바로 열어 level·chip view로 보고, 누락 소스는 알려 줍니다.
- **캡처·보고**: CLI 한 줄로 영역·에러별 PNG를 찍고, 문제 영역만 OASIS로 잘라 보냅니다.

## 6. 시작은 세 단계

1. tar 파일을 풀고 `./selfcheck`로 점검합니다.
2. `./floe2 index chip.oas`로 인덱스를 한 번 만듭니다.
3. `./floe2 view chip.oas`로 엽니다. 이후에는 누구나 바로 엽니다.

## 7. 문안 사용 시 주의 (내부용, 팜플렛에는 싣지 않음)

- 광역 뷰(fit, 1000 µm급) 비교 배수는 현재 floe2가 밀도 표현 없이 덜 그린 값이라
  헤드라인에 쓰지 않는다. 대표 점 적용 후 재측정한 값으로 교체한다.
- "8초"는 두 번째 열기 값이다. 인덱스 직후 첫 열기는 76초였다.
- "5~10배"와 jobdeck "2배 이상"은 현장 사용자 실측 각주가 붙은 값이다.
- 현재 범위(§5 of FLOE2_INTRO): plain OASIS만, jobdeck의 pick/snap/clip 미지원,
  Calibre의 waived 표기 미반영, UI 문구 영어. 이 제약을 숨기는 문장은 쓰지 않는다.
