## 도형의 깊이 분포

- **MAIN01.oas**: 최대 depth는 15지만, 대부분의 도형은 **depth 0–5**에 있다
  (사용자 제공). 성능 비교 시 얕은 depth도 주요 부하 구간으로 다룬다.

`precision`과 `file size`는 사용자 제공 표기를 그대로 보존했다.
앞서 별도로 전달된 `file size 9375M`은 **MAIN01.oas**에 해당한다.
도형·배치 개수의 집계 방식(명시 레코드 수인지, 반복/계층 전개 후 수인지)은
제공 정보에 명시되지 않았으므로 이 표에서 별도로 해석하지 않는다.

## MAIN01 OVR 생성 및 표시 실측 — 2026-09-18

사용자 제공 결과. `MAIN01 --representatives-only` 재실행이 총 **595.3 s**에
완료했다. OVR 생성·인코딩·저장 구간은 **147.8 s**이며, 아래 수치는 로그 그대로다.

```text
[vfs] representatives groups=2146 directory=1191003
peak_requests=4194304 points=4194304 161M (147.8s)
```

- 기존 멤버 디렉터리 상한 실패 이후, 배치당 엔트리를 저장하지 않는 생성 경로로
  해당 실칩의 OVR 생성이 완료됐다. 저장 점 수와 최대 진행 요청 수는 모두
  4,194,304개다. 실제 최대 RSS는 이 로그에 없다.
- 총 시간과 OVR 구간의 차이는 447.5 s다. 파싱을 포함한 나머지 실행 구간의
  합이며, 파싱만의 실측 시간으로 해석하지 않는다.
- 사용자 화면 확인: fit view의 밀도가 Calibre보다 크게 낮다. 확대해도 대표는
  계속 점으로 보이다가 어느 순간 원본 도형으로 바뀌어 표시 변화가 크다.
- 필요한 표시: 프론티어 헤어라인처럼 실제 크기에 따라 축소되는 형상과,
  확대할 때 추가되는 디테일. 현재 OVR1의 고정 대표 점만으로 이 요구가
  충족되지 않았다는 실칩 결과로 기록한다.

대표 파일의 생성·조회 방식과 진단 항목은
