# 웹/Electron 전환 잔여 작업 — 2026-09-25 정리

현재 구현 범위의 정리표다. `WEBUI_PLAN`과 각 단계 문서의 날짜별 기록은 보존하되,
예전의 “미구현/미검증” 문구를 현재 잔여로 중복 계산하지 않는다.
이번 사용자 요청은 **실제 테스트를 제외한 나머지 진행**이다. 실제 GUI·현장 실행을
단위 검사로 대체 통과시키지 않으며, 명시적으로 보류된 기능을 임의로 재개하지 않는다.
이번 기능·자동 검증 커밋은 `374452b`이며, 후속 문서 커밋은 잔여 범위 분리만 한다.

**후속 사용자 결정: NFS 지원 보류.** NFS 전용 구현·보완·현장 수용은 현재 필수
완료 조건에서 제외한다. 저장·복구의 개발/수용 기준은 우선 로컬 파일시스템이다.
기존 안전 장치를 제거하거나 NFS 경로 접근을 새로 차단하는 결정은 아니며,
현재 동작을 NFS 지원 보장으로 해석하지 않는다. RHEL/ETX 수용은 별도로 남는다.

## 1. 승인된 비실측 구현

| 범위 | 현재 상태 / 근거 |
|---|---|
| Rust 서비스·CLI, 일반/잡덱 열기·색인·렌더, 공통 웹 UI | 구현됨. Python/KLayout은 개발 오라클·기존 GTK 비교 경로에 남고 제품 실행 의존성이 아님 |
| 메뉴·CLI parity, 파일 선택·설정·내보내기·진단 | 구현 및 로컬 자동 게이트 연결. 목록 검사는 실제 UI 수용과 다름: [G4](WEBUI_G4_AUDIT.ko.md), [M4](WEBUI_M4.ko.md) |
| Electron 단일 호스트, 메뉴·파일 I/O·클립보드·복구·창 재사용 | 구현됨. 기존 macOS 합성 검사 기록 보존: [Electron](WEBUI_ELECTRON.ko.md), [창 재사용](WEBUI_NATIVE_INSTANCE.ko.md) |

| 로컬 Follow/Explore 공유 | 기존 opt-in/loopback 구현 유지. 원격 공개로 확장하지 않음 |

이 목록에서 지금 추가 구현 대상으로 확인된 공유 기본값 복구·일반 게시 불명 처리는
닫았다. 이것을 전체 전환 goal의 완료 또는 모든 입력에 대한 무결함 보증으로 쓰지 않는다.
새 실측에서 발견되는 회귀/성능 문제는 별도 이슈로 다시 연다.

## 2. 실제 테스트 대기 — 이번에 실행하지 않음

| 항목 | 필요한 확인 |
|---|---|
| 새 공유 기본값 복구의 실제 UI | 미리보기·기본 취소·명시 승인·응답 유실·reload·read-only check·기존 화면/파일 보존 |
| 파일 복구 중 Rust 서비스 자체 종료/새 세션 | 신규 승인 필요, 이전 승인/자동 저장 재생 없음, 표식/두 링크 보존과 재열기 |
| RHEL8.6/8.10 + ETX/X11 | runtime 의존성, sandbox, 첫 프레임·픽셀·파일 선택·클립보드·종료/창 재사용, Python 없는 실행 |
| 로컬 파일시스템 저장·복구 | 대상 OS의 권한·xattr/ACL·중단/재시작·durability. NFS 검증과 구별 |
| G1/G2/G4 실제 수용 | GTK 대비 동일 조건 성능/메모리·입력 지연, 물리 키·드래그·IME·DPI·focus/접근성, 현장 Firefox |
| 실제 오프라인 배포 환경 | 배포 archive를 격리된 대상에서 실행, 업데이트/롤백·고지 검토 |

단위 테스트의 합성 hard-link gap·모의 syscall 오류는 실제 NFS 장애/서비스 kill이
아니다. macOS 결과를 Linux 결과로 환산하지 않는다. `cargo check`, Node DOM 회귀,
권한 AST 검사는 위 실제 테스트를 닫지 않는다. 이번 선택 배터리도 전체 배터리의
새 통과 기록이 아니다.

## 3. 정책·권한·설계상 보류 — 테스트만 남은 것으로 오해하지 않음

- **NFS 지원**: 사용자 보류. NFS lock/xattr/ACL, RPC 결과 불명, 다중 client·재마운트,
  서버 장애/durability 대응과 현장 수용은 재개 요청 전까지 진행하지 않는다.
- **원격 공유 SH-10**: 사용자가 보류. HTTPS proxy/public exposure·사내 인증·인증서/
  방화벽 변경을 이번 “나머지”에 포함하지 않는다.
- **유료/외부 CI 실행**: GitHub Actions 실행 보류 유지.
- **M5 world-tile**: F2R-03c/10 및 실측에 따른 조건부 단계. 미구현이며 완료 처리하지 않는다.
- **열린 인덱스 hot-reload/공유 캐시 수명주기**: 서버-클라이언트 운영 정책 후속 논의 유지.
- **WKWebView 전용 호스트**: `617909e` 동결. 기능 추가·교차 호스트 수용은 필수 잔여에서 제외.
- **정식 서명·공증·배포/업데이트 운영 승인**: 개발 번들 생성과 별개. 인증서/계정/배포 대상/
  보안 정책을 임의로 만들거나 적용하지 않는다. GTK 비교 패키지 은퇴도 별도 판단이다.
- 무표식 orphan/target 없는 stage의 자동 청소, 타 NFS client의 증거 강제 채택은
  구현 결손을 숨기는 fallback으로 추가하지 않는다. 별도 안전 설계 없이는 자동 삭제 금지.

따라서 보고 문구는 **“현재 승인 범위의 비실측 구현 정리 완료; 실제 수용과 명시적
보류 단계는 남음”**이다. 커밋 수를 분모로 삼은 진척 백분율은 제공하지 않는다.
